# Rename Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `textDocument/prepareRename` and `textDocument/rename` for targets whose every use is provably in the open file.

**Architecture:** A new handler `crates/server/src/handlers/rename.rs` finds the target the way references does (`references::target_at`). It accepts only a `Target::Decl` that is a variable, or a private field or method. It collects the uses with `definition_in` over `identifier_spans_in`, and refuses on any token it cannot account for. One semantic helper, `javelin_semantic::exposes_member`, answers whether the declaring type's whole member walk already has the new name.

**Tech Stack:** Rust, lsp-types 0.97 (`RenameParams`, `TextDocumentPositionParams`, `PrepareRenameResponse`, `WorkspaceEdit`).

**Spec:** docs/superpowers/specs/2026-10-13-authoring-verbs-design.md, slice 1.

## Global Constraints

- No panic on the request path. A refusal is `None` from prepareRename and a `RequestFailed` from rename.
- Ambiguity answers nothing: any token spelled like the target that could be the target and resolves to nothing refuses the whole rename.
- `SURFACE` in `crates/cli/tests/reachability.rs` must list `textDocument/prepareRename` beside `textDocument/rename`.
- 100-column lines, comments explain why.

## Review Focus

- A private field under Lombok (`@Getter` on the class): it must be refused, because `getFoo()` uses go unrenamed.
- A private method named in `@MethodSource("foo")`: it must be refused.
- A local renamed to a name a field uses in its scope (`count = b;` with field `b`): it must be refused, because the field use would be captured.
- An unqualified private-method call from an anonymous class body: it must be refused.
- A rename asked while a reparse is in flight (stale view): it must be refused.

### Task 1: semantic `exposes_member`

**Files:** Modify `crates/semantic/src/members.rs` and `crates/semantic/src/lib.rs` (the export).

**Produces:** `pub fn exposes_member(files: &Files<'_>, externals: &dyn Externals, decl: &javelin_parser::Decl, name: &str) -> Option<bool>`.
- `Some(true)` means the type's static or instance walk has a member named `name`, or `name` is one of Object's methods.
- `Some(false)` means both walks are `whole_but_object` and none has it.
- `None` means it cannot say.

- [ ] Test: in a file `class A extends B { private int a; } class B { int b; }`, `exposes_member(A, "b") == Some(true)` and `"c" == Some(false)`. With `class A extends Missing {}` it returns `None`.
- [ ] Implement it with `infer::declared` and `walk_members` for `statics` false and true.
- [ ] Run `cargo test -p javelin-semantic exposes_member`.

### Task 2: rename handler, variables

**Produces:**
